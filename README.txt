MEDAL MOUNT – LG PORTRAIT TV DISPLAY

Purpose
-------
Standalone digital-signage page for the LG TV mounted physically in portrait orientation.
The LG webOS browser continues to render in landscape, so this page rotates the complete
signage canvas 90 degrees clockwise.

Deploy
------
Upload index.html to the root of a GitHub repository and enable GitHub Pages.
Then test the generated github.io address on the LG before connecting display.medalmount.com.au.

Current features
----------------
- Australia/Sydney clock and date
- Existing APPROVED Australian Service History logic/data
- Shop hours and contact details
- Portrait-TV software rotation
- Periodic page refresh retained
- Image placeholders retained until final shop image URLs are selected
- Weather placeholder retained until a commercial-safe weather source is connected

IMPORTANT
---------
Do not paste this standalone version back into the normal GoDaddy Website Builder page.
It is intended to be served as its own full-screen webpage.
